# Applied AI

Notes on applied AI — agents, RAG, multi-step LLM systems, harness and loop engineering — plus paper reading and reproduction.

Obsidian markdown, Mermaid diagrams inline.

## Layout

```
Applied AI.md            hub / index
PLAN.md                  10-stage concept plan (P0→P2), what to learn in what order
INTERVIEW-QUESTIONS.md   checkpoint bank, one section per stage
<concept>.md             deep-dive note, only when a concept outgrows a PLAN checkbox
```

## Method

Every concept note has to land in something real. If a concept never shows up in a working system, it isn't learned — it's read.

## Reading it outside Obsidian

`[[wikilinks]]` render as plain text on GitHub. Filenames match, so links are navigable by hand.
