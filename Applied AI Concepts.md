# Applied AI Concepts

Part of [[AI-Learning]]. Broader bucket for practical/production AI concepts that aren't specifically [[Harness Engineering]] or [[Loop Engineering]].

## Core concepts to learn
- [ ] RAG (Retrieval-Augmented Generation) — chunking strategy, embedding choice, retrieval ranking, when RAG beats fine-tuning (directly used in [[Genora]]'s retrieval over past posts)
- [ ] Prompt engineering fundamentals — few-shot vs zero-shot, system prompt design, structured output (JSON mode/tool-forced output)
- [ ] Fine-tuning vs. in-context learning — when fine-tuning is actually worth it vs. better prompting/RAG
- [ ] Evals — how to measure whether an LLM pipeline is actually working (not just vibes) — golden datasets, LLM-as-judge, human eval
- [ ] Multi-agent systems — pipeline (sequential handoff) vs. orchestrator/worker vs. debate patterns, and when each fits
- [ ] Embeddings & vector search — similarity metrics, index types (HNSW etc.), tradeoffs at scale
- [ ] Context engineering — what to put in the context window and in what order/format to get reliable output (distinct from prompt wording)
- [ ] Model deprecation/versioning — tracking provider model lifecycles, migration paths (directly relevant to [[DepLyx]]'s core feature)
